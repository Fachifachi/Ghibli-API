Ghibli Explorer es una aplicación web que te permite explorar el universo de Studio Ghibli utilizando la API oficial de Ghibli. Construida con React y Tailwind CSS, esta aplicación proporciona una interfaz atractiva y dinámica para descubrir películas y personajes del aclamado estudio de animación japonés.

Características
Exploración de Películas: Navega a través de la filmografía de Studio Ghibli y obtén detalles sobre cada película.
Detalles de Personajes: Descubre información sobre los personajes de las películas.
Diseño Moderno: Interfaz estilizada con Tailwind CSS para una experiencia visual agradable y responsiva.
Tecnologías Utilizadas
React: Biblioteca para construir interfaces de usuario interactivas.
Tailwind CSS: Framework de CSS para un diseño moderno y flexible.
Vite: Herramienta de construcción y desarrollo rápida para proyectos frontend.
Axios: Cliente HTTP para realizar solicitudes a la API de Ghibli.
React Router DOM: Enrutamiento para la navegación dentro de la aplicación.
Wouter: Enrutador ligero para React (opcional, dependiendo de cómo implementes la navegación).
